# KP Astrology Chart Generator (Front-End Only)

This project creates a web page to input details for generating a KP (Krishnamurti Paddhati) astrology chart.

**Current Status:** This is a front-end only implementation. The core astrology calculation logic is not yet implemented. The page will display a placeholder message when you click "Generate Chart".

## How to Run

1.  **Clone the repository or download the files.**
2.  **Open `index.html` in your web browser:**
    *   Navigate to the directory where you saved the files.
    *   Double-click on the `index.html` file.
    *   Alternatively, right-click on `index.html` and choose "Open with" your preferred web browser.

You should see a web page with a form to enter birth details. When you fill out the form and click "Generate Chart", a message will appear below the form indicating that the chart generation is pending.

## Files

*   `index.html`: The main HTML structure of the web page.
*   `style.css`: Contains the CSS styles for the page.
*   `script.js`: Contains the JavaScript to handle form input (currently shows a placeholder).
